# Orbit Store 0.6.5 (Beta)

**More control from your TV.**

- **Settings in the native app.** Choose download sources, set your default drive, pair a phone and refresh the catalogue without leaving Orbit.
- **Updates in one place.** Check and update the TV app and download service separately. Orbit lets you know when a newer version is available; you choose when to install or restart.
- **Continue Vikingfile downloads in the browser.** Your selected game, source and destination carry over from the TV app. Open the download page on PS5, press Download there, then return to Orbit.
- **Browser improvements.** Less background work on Discover and game details, with artwork backups when a banner fails to load.
- **Clearer storage results.** Completed operations use a compact summary, with file details available when you need them.
- **More game information.** Expanded release dates, publisher and genre metadata improve browsing and sorting.
